# WSL Setup

The ZIP extracts into a single folder named:

`Auburn ML Research - Minimal ALS Speech Assessment`

## Recommended location

Copy the ZIP into your WSL home directory, then run:

```bash
unzip "Auburn ML Research - Minimal ALS Speech Assessment.zip"
cd "Auburn ML Research - Minimal ALS Speech Assessment"
git init
git add .
git commit -m "Initialize Auburn ALS speech assessment research project"
```

Do not download VOC-ALS or begin implementation until the project plan is explicitly approved. When data work begins, retain immutable raw files locally and do not commit participant-level audio or generated data unless the dataset license and repository policy explicitly permit it.
